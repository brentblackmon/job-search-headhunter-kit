# Target companies

Up to 25 companies the user wants to work for. Every scan checks each careers page and records new openings in the user's role family with the date first seen. A posting on the company's own site is the primary source. Workday pages (myworkdayjobs.com) and search-box careers pages show no listings to a plain page fetch, so the scan checks web search and job boards for those and notes "careers page not readable, checked job boards instead" when it cannot read the page itself.
