# Site pages

Drop-in pages for brentblackmon.github.io, built in the same design system (dark hero, red accent, cream stat cards, Helvetica Neue).

- `recruit-rocket/index.html`: the animated Recruit Rocket team page. Copy the `recruit-rocket` folder into the root of the brentblackmon.github.io repo. It is self-contained (no dependency on `styles.css`) and links back to Home, Writing, Work, and About.

To add it to the site's other pages, add `<a href="../recruit-rocket/index.html">Recruit Rocket</a>` to each page's `.nav-links`.
